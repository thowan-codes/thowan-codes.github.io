## What it is
A core mod for other Voices of the Void mods created by Thowan. It provides information about the game without having to completely recreate the development research every time.

### Current Features
- Registers mods that implement it's registration API
  - Mods that register get access to information from Voices of the Void as well as other game details.
- Provides config editing to mods that register to it.

### Why I made it
I kept finding myself having to do the same research over and over again into the Voices of the Void UI and realized I could create a one stop shop for all the information I needed.

## Current focus

- Adding Config Loading, Editing, and Saving
